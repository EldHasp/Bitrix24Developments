# Bitrix24Developments

База разработок и решений для **Битрикс24** (облако).

## Что здесь хранится

| Раздел | Содержание |
|--------|------------|
| **internal/** | Бизнес-процессы, смарт-процессы, триггеры и другие настройки портала |
| **external/** | Интеграции и локальные приложения (ссылки и документация; код крупных проектов — в отдельных репозиториях) |
| **docs/** | Общие паттерны, ограничения облака, переиспользуемые решения |
| **apps/** | Небольшие сервисы/приложения (например API + активити БП) |
| **catalog.md** | Реестр всех разработок и связей между ними |

Полезные паттерны:

- [Локальное приложение + активити БП](docs/bitrix-local-app-activity.md) — где искать список, auth/BX24, регистрация `bizproc.activity.*`

## Связанные репозитории

- [GasBitrixCoreLibrary](https://github.com/EldHasp/GasBitrixCoreLibrary) (`BitrixCore_Library`) — библиотека Apps Script: REST Bitrix24 ↔ Google Sheets

Код библиотеки и отдельных приложений **не переносится** сюда — здесь остаются описания, решения и ссылки.

## Как пользоваться

1. Перед новым БП или интеграцией — поиск в `docs/`, `catalog.md` и похожих папках в `internal/` / `external/`.
2. После решения — зафиксировать: задача → ограничение → решение → где ещё применимо.
3. Общее выносить в `docs/`, частное оставлять в карточке конкретного процесса/приложения.

## Запросы к Битрикс24

Локальные REST-дампы (Node, без привязки к Apps Script): см. [tools/bitrix/README.md](tools/bitrix/README.md).  
Снимки API — в `snapshots/bitrix/`, выжимки под задачу — рядом с карточкой в `internal/` или `external/`.
