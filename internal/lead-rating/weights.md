# Таблица ID → вес (рейтинг лида)

Источник ID: [`bitrix-enums.json`](bitrix-enums.json) (выгрузка 2026-07-11).  
Шкала весов: Google-калькулятор «Калькулятор категории» — колонки **1…4**.

Формула:

```
avg = SUM(весов) / COUNT(весов)
```

В среднее попадают только значения с весом **1…4**.  
Если в поле выбрано **«Нет данных»** или пусто — **это поле пропускается** (не в числитель и не в знаменатель).

Пороги итога → **Рейтинг лида** (`UF_CRM_1783504656939`):

| Среднее | Категория | ID |
|---------|-----------|-----|
| 3.26 – 4.00 | А+ | `3484` |
| 2.51 – 3.25 | А | `3486` |
| 1.76 – 2.50 | В | `3488` |
| 1.00 – 1.75 | С | `3490` |

> Буквы **А / В / С** в Битрикс — кириллица.  
> Для долга используйте **Категория/сумма долга**, не старое «Сумма долга».

## Как хранить таблицу, чтобы использовать в БП

В облачном БП **нет** нормального словаря «ID → вес». Константы — только скаляры. Поэтому хранение разделяем на два уровня.

### 1. Источник правды (этот репозиторий) — обязательно

| Файл | Зачем |
|------|--------|
| [`weights.json`](weights.json) | Машиночитаемо: веса, ID «Нет данных», пороги |
| [`weights.md`](weights.md) | Читаемо при настройке БП |

При смене значений списка: обновить дамп enums → поправить `weights.*` → синхронизировать логику в Битрикс.

### 2. В самом Битрикс — что реально работает на «Профессиональный»

**Рекомендуемый вариант: скрытые числовые поля веса**

1. Семь служебных полей лида (число, только для автоматизации), например:
   - `Вес: категория/сумма долга`
   - `Вес: готовность ко встрече`
   - …
2. На изменение каждого списка — робот:
   - значение ∈ ID «Нет данных» / пусто → **очистить** поле веса;
   - иначе → записать **1…4** по таблице ниже.
3. Отдельный робот: среднее по **заполненным** полям веса → порог → записать `Рейтинг лида`.

Так таблица в БП «хранится» как ветки условий (ID → число), а «Нет данных» — как очистка веса. Перестройка = правка одной ветки + `weights.json`.

**Не рекомендуется:** пытаться держать весь словарь только в константах БП (ломко при смене списков).

**На вырост:** вебхук/Apps Script читает `weights.json` и считает рейтинг — одна точка правки, БП только вызывает расчёт.
